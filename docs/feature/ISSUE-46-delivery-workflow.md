# 对齐五阶段交付流程

- 父需求：https://github.com/yujiewanwan/prime_prd/issues/8
- 迭代：202609-2

## 范围

统一任务接收、状态回写、周迭代及 Issue URL 追溯，更新 Agent 规则、模板与校验。保留产品构建和测试。本期不增加后台领取、执行或自动合并。

## 完成标准与验证

- [ ] 规则、模板、校验使用相同五阶段和追溯格式。
- [ ] 正常交付可通过；旧编号、状态冲突及跨仓库关闭引用被拒绝。
- [ ] 单 PR、多 PR、失败、取消和父项汇总有明确执行规则。
- [ ] 校验回归测试及适用 CI 通过。

不涉及产品代码、数据库、业务查询性能或服务启动。

## 独立审查与合并约束

PR 必须取得独立 Agent 对当前提交的 review，通过且无未处理意见后才能待合并，用户授权后才能合并。CI、自查和点击 Resolve 不能代替审查。Agent Review Gate 只执行默认分支可信脚本，并检查最新交付状态；API 错误和证据不足不视为通过。

校验覆盖非空范围、交付类型移除、PR 拒绝复用已关闭或未开始的任务、提交正文的隐藏关闭引用。Issue 关闭/重开事件保留最终校验；短暂时差最多重读 25 秒，持续不一致仍须修正。
